# Page Title

The primary heading at the top of a page that identifies its purpose, with optional Back Button, inline Icon, and supporting Description.

---

## Guidelines

### When to use

- At the top of every page to establish clear navigational context

- Include the Back Button when the page is reached via a multi-step flow or a drill-down from a parent page

- Include the Icon when the page is scoped to a specific asset, token, or entity that benefits from visual reinforcement

- Include the Description when the page purpose is not self-evident from the title alone, or when a brief instruction helps reduce user error

### When not to use

- Don't use the Description to repeat what the title already communicates — omit it if it adds no new information

- Don't use the Icon as decoration; only include it when it carries meaningful identification context

- Don't include the Back Button on top-level pages that have no logical parent

---

## Behavior

- Back Button, Icon, and Description are independently optional — they can be combined in any configuration depending on page needs

- The Icon renders inline within the same row as the Page Title; it does not break to a new line

- The Description wraps naturally across multiple lines if the content exceeds the available width

- Text style is the only difference between desktop and mobile variants — spacing and layout structure remain unchanged

## Placement

- Positioned at the top of the page content area, above all other page elements

- Spans the full content column width

- Back Button, when present, sits above the Page Title row as its own line
